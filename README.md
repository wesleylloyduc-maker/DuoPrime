# DuoPrime Maintenance

DuoPrime Maintenance is a premium property maintenance and decorating contractor serving Greater Manchester. This repository contains a polished multi-page website for the business, including a homepage, service pages, project gallery, coverage areas, contact form, and thank-you page.

## Structure

- index.html — homepage with hero slider, counters, testimonials, and CTA
- about.html — business overview and standards
- services.html — core service descriptions
- projects.html — project gallery with filtering and lightbox preview
- areas.html — coverage areas across Greater Manchester
- contact.html — enquiry form connected to FormSubmit
- thank-you.html — confirmation page
- assets/css — global styling, responsive rules, and animation styles
- assets/js — navigation, sliders, counters, and gallery interactions

## Deployment

The site is ready for GitHub Pages. After pushing the repository to GitHub, open Settings → Pages and publish the main branch.
