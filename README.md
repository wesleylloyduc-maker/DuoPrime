🧱 DuoPrime Maintenance — Official Website Repository
🌟 Overview
DuoPrime Maintenance is a Manchester‑based property maintenance company delivering high‑quality residential and commercial services.
This repository contains the full source code for the DuoPrime website — a modern, responsive, service‑focused platform designed to showcase your work, brand identity, and customer contact pathways.

The project is built with clean HTML, modular components, SCSS architecture, and lightweight JavaScript for interactivity.

🚀 Features
Fully responsive layout across mobile, tablet, and desktop

Modular component‑based structure for easy updates

Service gallery for Repairs, Painting, Pressure Washing, and Property Maintenance

Before‑and‑after project showcase

SEO‑optimised metadata and structure

Contact form with validation and email forwarding

Brand‑consistent UI using DuoPrime’s navy‑and‑gold palette

Lightweight, fast‑loading, and easy to maintain

📦 Installation
bash
# Clone the repository
git clone https://github.com/yourusername/duoprime-website.git

# Navigate into the project directory
cd duoprime-website

# Open the project
start index.html   # Windows
open index.html    # macOS
